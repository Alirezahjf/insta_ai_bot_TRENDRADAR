# 🤖 ربات هوشمند اسکرپ و تحلیل اینستاگرام

اسکرپ هشتگ اینستاگرام با **Apify** + پیشنهاد کلیدواژه‌ی تازه برای هر اجرای اسکژول با **AvalAI** + جست‌وجوی همان عبارت‌ها در Telegram + انتخاب برترین پست با **الگوریتم وایرال‌اسکور**.

## ✨ امکانات

| بخش | توضیح |
|---|---|
| 🔍 اسکرپ جدید | اسکرپ فوری: هشتگ → تعداد → نوع → کامنت → نتیجه کامل |
| ⏰ اسکژول اسکرپ | اجرای خودکار سر ساعت‌های تهران + گزارش کامل + تحلیل AI |
| 🔎 گسترش جست‌وجو | AvalAI در هر اجرای اسکژول تا ۵ عبارت تازه می‌سازد؛ تاریخچه‌ی هر اسکژول از تکرار عبارت‌های تولیدشده جلوگیری می‌کند |
| 📡 جست‌وجوی دوپلتفرمی | همان هشتگ‌های پایه و عبارت‌های تازه به Apify برای Instagram و TrendRadar برای جست‌وجوی Telegram داده می‌شوند |
| 🤖 تحلیل AI | انتخاب «تک‌پست برتر» از بین ۳ تای برتر + دلیل + قوت/ضعف + راهنمای پست‌گذاری |
| 🔥 وایرال‌اسکور | امتیاز ۰–۱۰۰ هر پست با الگوریتم شفاف |
| 📜 ران‌های قبلی | مرور ران‌های Apify + دانلود/نمایش کامل خروجی (بدون پرداخت دوباره) |
| ⭐ آخرین خروجی | نمایش آخرین نتیجه با یه کلیک |
| 🗑️ سطل آشغال | حذف نرم اسکژول‌ها + برگردوندن + حذف کامل |

## 🧪 الگوریتم وایرال‌اسکور

```
امتیاز = 30% بازدید (لایک نسبی) + 25% گفتگو (کامنت و نسبت کامنت/لایک)
       + 20% ویو (ریلز/ویدیو) + 15% تازگی (نیمه‌عمر ۴۸ ساعت) + 10% کیفیت کپشن
```

امتیازها **نسبی به همون بچ اسکرپ** هستن، پس روی هر هشتگی (کوچیک/بزرگ) درست کار می‌کنن.

## 🚀 نصب و اجرا (ویندوز)

```bash
# ۱) پایتون 3.10 به بالا نصب کن (از python.org + تیک Add to PATH)

# ۲) برو تو پوشه پروژه و پکیج‌ها رو نصب کن
pip install -r requirements.txt

# ۳) فایل .env را تنظیم کن:
#    TELEGRAM_BOT_TOKEN  → از @BotFather
#    APIFY_API_TOKEN     → از console.apify.com > Settings > Integrations
#    AVALAI_API_KEY      → از پنل avalai.ir > API Keys (برای کلیدواژه‌سازی و تحلیل)
#    ADMIN_IDS           → آیدی عددیت از @userinfobot
#    برای جست‌وجوی Telegram (اختیاری): TG_API_ID و TG_API_HASH از my.telegram.org
#    برای ورود یک‌باره و ساخت session اجرا کن: python -m trendradar.tools.trend_cli login
#    جست‌وجو خودکار عضو کانال‌ها نمی‌شود؛ نبود تنظیمات/ورود Telegram فقط هشدار می‌دهد.

# ۴) اجرا
python bot.py
```

اگه همه‌چیز درست باشه می‌بینی:

```
🤖 Bot is running... | Tehran: 2026-09-21 15:30
🤖 AI model: gpt-4o-mini @ https://api.avalai.ir/v1
⏰ Scheduler started (Asia/Tehran)
```

## ⏰ اسکژول چطور کار می‌کنه؟

1. دکمه **⏰ اسکژول اسکرپ** → **➕ اسکژول جدید**
2. ساعت‌ها رو به وقت تهران بده: `08:00, 12:30, 20:00`
3. هشتگ‌ها، تعداد، نوع (پست/ریلز/هر دو)، تنظیمات کامنت
4. ذخیره → در هر نوبت اسکژول:
   - AvalAI تا ۵ کلیدواژه‌ی تازه می‌سازد و با تاریخچه‌ی پایدار، عبارت‌های تولیدشده‌ی قبلی همان اسکژول را تکرار نمی‌کند. هشتگ‌های پایه‌ی کاربر همچنان برای پایش مستمر استفاده می‌شوند.
   - فهرست یکسان (هشتگ‌های پایه + پیشنهادهای تازه) به Apify برای جست‌وجوی Instagram و به TrendRadar برای جست‌وجوی Telegram فرستاده می‌شود.
   - نتیجه‌ی Telegram جداگانه و فشرده گزارش می‌شود؛ نبودن تنظیمات/ورود Telegram یا خطای AvalAI مسیر Instagram را متوقف نمی‌کند.
   - 📊 خروجی Instagram + فایل CSV و JSON + پست‌های برتر؛ در صورت فعال بودن، کامنت‌ها و تحلیل AI نیز ارسال می‌شوند.

> ⚠️ برای اجرای سر ساعت، برنامه `bot.py` باید روشن باشد. جست‌وجوی Telegram به `TG_API_ID`, `TG_API_HASH` و session واردشده نیاز دارد؛ قابلیت جست‌وجو هرگز خودکار عضو کانال‌ها نمی‌شود.

## 🤖 تغییر مدل AI

تو `.env`:

```
AVALAI_MODEL=gpt-4o-mini
```

می‌تونی بذاری `gpt-5-mini` یا هر مدل دیگه‌ای که تو پنل AvalAI داری.

## 🗂 ساختار پروژه

```
bot.py            → نقطه ورود + روترها
core.py           → ربات، کیبوردها، ابزارها
jobs.py           → نمایش نتایج + پایپ‌لاین‌ها + اسکژولر
instant_flow.py   → فلو اسکرپ فوری
sched_flow.py     → فلو اسکژول/ویرایش/سطل آشغال
runs_flow.py      → مرور ران‌های قبلی
apify_service.py  → ارتباط با Apify
ai_service.py     → ارتباط با AvalAI + تولید کلیدواژه و تحلیل
search_service.py → تاریخچه‌ی کلیدواژه‌ی اسکژول + اسکن Telegram
scoring.py        → الگوریتم وایرال‌اسکور
database.py       → SQLite اسکژول‌ها و تاریخچه/لاگ کلیدواژه
schedules.db      → خودکار ساخته میشه (اسکژول‌ها اینجان)
```

## ❓ مشکلات رایج

| مشکل | راه‌حل |
|---|---|
| `TELEGRAM_BOT_TOKEN رو تو .env بذار` | فایل `.env` رو پر کن (نه `.env.example`) |
| فقط ۱ نتیجه برمی‌گرده | محدودیت پلن Free آپی‌فای برای هشتگه؛ پلن Starter می‌خواد |
| تحلیل AI خطا میده | کلید AvalAI + شارژ حساب رو چک کن؛ مدل رو هم چک کن |
| اسکژول سر ساعت اجرا نشد | برنامه باید اون لحظه روشن باشه؛ ساعت رو به وقت تهران بده |
| `'Run' object is not subscriptable` | قبلاً فیکس شده؛ مطمئن شو فایل‌های جدید رو اجرا می‌کنی |
